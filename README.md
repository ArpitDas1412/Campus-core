# CampusCore — AI-Powered Campus-to-Corporate Placement Management & Analytics Platform

**CampusCore** is an enterprise-grade placement management ecosystem built across 13 integrated operational layers that connect students, university placement officers, and corporate recruiters.

## Key Capabilities Across 13 Operational Layers

1. **Layer 1: Enterprise System Shell & Design System**
   - Cohesive multi-role navigation and responsive interface with role-based routing.
2. **Layer 2: Placement Officer Command Center**
   - High-level dashboards with real-time cohort tracking and administrative statistics.
3. **Layer 3: Student Readiness & Profile Engine**
   - Comprehensive student profiles, verified academic data, and project showcases.
4. **Layer 4: AI Skill Gap Intelligence & Recommendation Engine**
   - Automated market skill benchmarking, gap analysis, and tailored learning paths.
5. **Layer 5: Resume Intelligence & ATS Scoring**
   - Parsing, keyword auditing, ATS-readiness scoring, and career signal extraction.
6. **Layer 6: Recruiter & Corporate Management Portal**
   - Job posting, candidate pipeline monitoring, and recruitment preference controls.
7. **Layer 7: AI Candidate Matching & Talent Discovery**
   - Multimodal algorithmic candidate matching against job criteria.
8. **Layer 8: Explainable AI Fit Score & Match Transparency**
   - Transparent scoring breakdown, strengths, gaps, and decision factors.
9. **Layer 9: Smart Shortlisting & Decision Engine**
   - Multi-stage shortlisting pipelines, recruiter notes, and status management.
10. **Layer 10: Conflict-Aware Interview & Drive Scheduler**
    - Multi-track interview schedule builder with automatic conflict detection.
11. **Layer 11: Intelligent Communication Center & Notification Dispatch**
    - Announcements, multi-channel templates, message threads, and real-time alerts.
12. **Layer 12: Offer & Document Lifecycle Tracker**
    - Offer generation, student accept/decline flows, document upload, verification audit log, and joining tracking.
13. **Layer 13: Campus Intelligence & Executive Analytics**
    - Comprehensive placement funnel analytics, CTC breakdowns, department trends, and recruiter metrics.

## Getting Started

```bash
# Install dependencies
npm install

# Start local development server
npm run dev

# Build production bundle
npm run build
```
